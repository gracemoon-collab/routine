# 하루 20뽀모 — 전환기 루틴

뽀모도로 타이머와 하루 기록을 한 화면에 둔 개인용 웹앱.

- **코어 15뽀모 + 재량 5뽀모** = 하루 20뽀모
- 항목별로 다르게 묻는 기록 (계시록 장·절, 독서 책·쪽, 중국어 구분 …)
- 3단 최소선으로 무너지는 날을 미리 설계한다
- 노션에 붙는 CSV 내보내기

## 데이터

**기록은 브라우저(localStorage)에만 저장됩니다.** 서버로 보내지 않고, 이 저장소에도
올라가지 않습니다. 기기를 바꾸면 백업 파일로 옮기세요.

## 설치

주소를 열고 → 공유 → **홈 화면에 추가**.

## 빌드

이 저장소는 배포 산출물입니다. 원본과 빌드 스크립트는 개인 저장소에 있습니다.
